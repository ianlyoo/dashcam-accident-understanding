# Lessons

1. **과제 정의를 구현 가능한 기하로 옮긴다.** 충돌 차량이 자차 통로에 진입하는 순간을 추적한 S161은 18개 공식 적중을 더했다. AI가 만든 진입 라벨이나 첫 프레임 편법은 전이되지 않았다.
2. **로컬 OOF와 공개 점수를 분리한다.** Nexar 충돌 OOF가 크게 올라도 숨은 시험의 이익은 1/4~1/10 수준까지 줄었다. comma2k19의 가속 보정도 로컬 +0.046 macro-F1에 반해 공식 S3를 0.0865 낮췄다.
3. **업로드의 인과성을 설계한다.** S170→S171은 진입만, S171→S172는 충돌만 바꿔 18개와 6개 적중을 셀 수 있었다. S185와 S182는 S176의 순효과를 격리했다.
4. **작은 라벨 패널의 불확실성을 인정한다.** S176은 한 사람 라벨 패널에서 0/8이었으나 공식 점수는 소폭 상승했다. 패널의 출처·표본 편향을 같이 기록해야 한다.
5. **실행 시간은 모델 품질의 일부다.** 60분 제한에서 단계별 시간 예산, 캐시, 실패 시 기존 출력 사용이 필수였다. 로컬 추정과 서버 실행의 차이는 약 -6.4분에서 +3.6분이었다.
6. **재현 자료를 실험과 함께 만든다.** 최종 제출의 코드와 규칙은 남았지만 학습 데이터·가중치·정확한 원천별 매니페스트와 처음부터 끝까지의 재생 명령은 이 공개 저장소에 없다. 차기 프로젝트는 학습 설정, 데이터 해시, 가중치 출처와 예측 계약을 릴리스마다 고정한다.
